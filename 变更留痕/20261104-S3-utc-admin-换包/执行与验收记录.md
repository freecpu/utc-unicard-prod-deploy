
## 八、本次踩到并已修的 4 个工具缺陷

| # | 缺陷 | 后果 | 修法 |
|---|---|---|---|
| 1 | `probe-utc-runtime.sh` 的 `error_distinct_types` 用 `[A-Za-z.]*Exception`（允许零长前缀） | 报出伪类型 `Exception`，一度像是换包引入新异常 | 改为 `[A-Za-z][A-Za-z0-9_.]*Exception` |
| 2 | `analyze-error-delta.sh` 与 runtime 探针用了**不同正则** | 两份输出不可比，交叉验证失效 | delta 脚本增加 `_runtime_regex` 对照块 |
| 3 | `probe-utc-http.sh` 的 `sha_norm` 归一化写成 `"timestamp":[0-9]*` | Spring 实际输出是**带引号的 ISO-8601 串**，`[0-9]*` 匹配零字符，归一化完全失效；且 ISO 串长度恒定使 `bytes` 列不变，单看 bytes 会漏掉 | 改为 `"timestamp":"[^"]*"`，并加「连跑两次 diff」验证步骤 |
| 4 | `analyze-error-delta.sh` 用 `sed -n "/date.time/,\$p"` 切片 | error 日志里没有以该分钟开头的时间戳行 → 静默返回 1 行，假阴性 | 改 awk：日期前缀行更新标志位、堆栈续行继承 |

另有 PowerShell → ssh 剥引号导致内联命令失败 2 次（`grep -A8 'window='`、`sed -n '/…/,$p'`），
纪律：**含空格、竖线、`$`、中文的任何远程命令一律写成脚本文件 scp 上去执行，不内联。**
