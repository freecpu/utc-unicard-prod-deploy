### 自纠（第 61 次·操作错误）

首次跑 creds 门禁时**漏传目录参数**，脚本默认扫 `/tmp`，输出 `CLEAN_PARTIAL / 101 个 NUL 文件`。
实际那 101 个是 `/tmp` 下 PowerShell 的 UTF-16LE 日志（`LAPTOP-*.log`），与仓库无关；仓库内 NUL 文件实测 **0 个**，本轮 7 个文件全部 UTF-8 无 BOM。
正确调用：`AUDIT_DEPTH=99 bash scripts/audit-tmp-creds.sh .`
教训：门禁脚本的"默认扫描面"≠"提交前扫描面"，调用必须显式传目录——否则无论报 CLEAN 还是报脏，结论都可能与本次提交无关。
