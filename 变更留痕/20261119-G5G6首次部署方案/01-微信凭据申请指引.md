## 二、公众号申请（若已有认证服务号可跳过本节）

1. 打开 mp.weixin.qq.com →「立即注册」→ 账号类型选**服务号**（订阅号无网页授权与支付能力，不可用）。
2. 填邮箱（未注册过公众平台的邮箱）→ 邮箱激活 → 选择主体类型（企业/个体工商户等）→ 填主体资料（营业执照、统一社会信用代码、对公账户等）→ 管理员身份验证（管理员微信扫码＋身份证信息）。
3. **微信认证**：服务号须完成微信认证才具备网页授权（OAUTH）与申请微信支付资格；认证费 300 元/年，审核约 1~5 个工作日（以微信当前流程为准）。
4. 认证完成后登录公众平台 →「设置与开发 → 基本配置」：记录 **AppID**；**AppSecret** 点「生成/重置」（需管理员扫码；Secret 只显示一次，妥善保存；重置会使旧 Secret 失效）。
5. 「设置与开发 → 公众号设置 → 功能设置」→ **网页授权域名**填 `www.xhc123.work`（需下载 MP_verify_*.txt 校验文件放到域名根目录可访问——届时告知 S0，由 nginx 静态承接）。
6. 若服务端调用微信 API 遇 IP 白名单拦截：「基本配置 → IP 白名单」加入第四台机出口 IP（坐标见台账 §20）。

## 三、微信支付商户号申请

1. 途径 A（推荐）：公众平台 →「微信支付」入口 → 按指引申请（与公众号自动关联）；途径 B：pay.weixin.qq.com 直接注册商户号。
2. 提交主体资料（营业执照/法人身份证/结算银行账户/客服电话等）→ 审核约 1~5 个工作日 → 通过后**在线签署协议**→ 获得**商户号 MCH_ID**。
3. 商户平台 →「产品中心 → AppID 账号管理」→ **绑定公众号 AppID**（绑定后 AGENTMP_WXPAY_APP_ID 即填该 AppID）。
4. 「产品中心 → 开发配置」：JSAPI 支付授权目录/回调域名按 `https://www.xhc123.work/` 配置（以商户平台当前要求为准）。

## 四、API 密钥与 p12 证书（资金面敏感，取得后走受控通道）

1. **APIv2 密钥**：商户平台 →「账户中心 → API 安全 → APIv2 密钥 → 设置密钥」→ 自设 **32 位**字符串（字母数字）→ 即 AGENTMP_WXPAY_API_SECRET。（本应用走 p12＋APIv2 老接口形态，yml/代码实读定案；无需 APIv3 密钥。）
2. **apiclient_cert.p12**：同页「API 证书 → 申请/下载证书」→ 下载**证书工具**（Windows）→ 工具内输入商户号 → 按指引生成证书请求串 → 粘贴回商户平台 → 平台签发后在工具内完成 → 工具导出 **apiclient_cert.p12**（证书口令默认＝商户号；应用侧消费在依赖库内，G5 接线时若需显式口令键再核）。
3. 证书文件含私钥，**勿经微信/邮件明文外传**；交付 S0 方式＝放本地临时路径告知，SSH 管道落机后即删本地副本（或用户自行上传机上 /data/apps/agent-mp/etc/）。
